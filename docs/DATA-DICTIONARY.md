# 拼版与纸耗计算

尺寸单位mm或cm统一到mm，纸张克重gsm为g/m²，纸价为CNY/kg。仅比较整版同方向正交网格的0°与90°，不宣称是任意混排的全局最优。grain=fixed不允许旋转。每个成品四边各加bleed，成品间gap；列数=floor((纸宽+gap)/(成品宽+2bleed+gap))。

净张数=ceil(印量/每张副数)，固定开机损耗单独加，运行损耗=ceil(净张数×loss_pct/100)，不得对含固定损耗的总数重复计百分比。每纸批按due、order_id顺序扣库存；不足整单不放行，库存不为负。余料仅为完整原纸，裁切边料不按原纸返库。毛重=总张数×面积m²×gsm/1000。按每批精确总成本四舍五入到分后最大余额分摊，保证订单成本和纸批总成本相等。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同order_id仅最高version参与生产计算，旧版保留采信证据；同版本业务字段冲突则整组隔离。同纸批库存、克重、纸价与尺寸按Decimal数值比较，数值相同的小数写法视为同一材质。

## 换纸裁决（M8）

裁决对象是临近交期、原纸批不足以整单放行的订单。对每个订单枚举原纸做法与每个可换纸批做法：尺寸或纹向不兼容（成品无法排入、grain=fixed不允许旋转）的纸批不具备换纸资格；按due、order_id顺序裁决，候选纸批的`available`为轮到该单时的剩余量，`feasible = gross <= available`。原纸可整单放行则坚持原纸，不触发换纸。

- 整单换纸（full，默认）：原纸不足时整单改投成本最低的可行换纸批，开机损耗只发生一次，原纸批余量被完整保留。
- 分段补足（split）：先用原纸批全部余量（二分反推在固定开机+印量损耗约束下可容纳的最大净张数），剩余印量由换纸批重新计净张并再承担一次开机损耗；两段张数、库存、成本与整单换纸均不同。仅当两段都可行时成立，否则回退整单换纸。
- 刚好够产：原纸不足且某可行换纸批的剩余量恰好等于整单需求gross。此时full与split得到不同每张排数、库存与订单成本，页面用`exact_fit`显式标注并说明本批选择。

裁决全程为预演：只有被选做法会在`projection`里扣减，未选中的候选纸批`consumed=0`、保持期初余量（no_preempt）；无任何可行做法的订单置SHORTAGE，不放行、不占用任何纸批。库存守恒`opening=consumed+closing`且closing非负；订单分币成本由各被选做法精确成本按最大余额法分摊，订单成本和等于精确成本和等于业务总成本。

封存为条件化、幂等操作：仅当整批对账（行数守恒、库存守恒、成本守恒、未选不预占、可行性）全部通过才写入seals台账；失败返回UNBALANCED并保留旧版。封存指纹由策略、每单选择与纸批投影决定，同一排产决定重跑`INSERT OR IGNORE`不新增用纸和订单成本；复核版本陈旧返回409。
